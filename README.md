## 🎮 Gameplay

O jogo consiste em sobreviver o maior tempo possível enquanto enfrenta inimigos e tenta bater seu próprio recorde.

## ⌨️ Controles

- **W** – mover para cima  
- **A** – mover para a esquerda  
- **S** – mover para baixo  
- **D** – mover para a direita  
- **Espaço** – atacar com a espada  
- **R** – ativar o ritual (poder especial)

## 🎯 Objetivo

Sobreviver o maior tempo possível enquanto derrota inimigos e usa seus poderes de forma estratégica.
